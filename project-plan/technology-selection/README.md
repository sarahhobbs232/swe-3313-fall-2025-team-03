## 🧪 Technology Plan — Eternal Elixers

Our team is building a small e-commerce website to sell unique potions using a lightweight, flexible tech stack. Below is a breakdown of our selected technologies and the rationale behind each choice.

### 🐍 Language: Python
We chose [Python](https://www.python.org/) for its simplicity, readability, extensive ecosystem of libraries, and the team members abilities. It’s ideal for rapid development and well-suited for web applications.

### ⚙️ Framework: Flask
We’re using [Flask](https://flask.palletsprojects.com/) as our web framework because it’s minimal, easy to learn, and integrates seamlessly with Python. Flask allows us to build scalable applications without unnecessary overhead.

### 📦 Storage Plan: JSON
Our data will be stored in [JSON (JavaScript Object Notation)](https://www.json.org/json-en.html) files. This format is lightweight, human-readable, and perfect for small-scale projects that don’t require a full database engine. It also pairs well with Flask for quick data access and manipulation.

### 💻 Operating Environment
- **OS**: Cross-platform (Windows, macOS, Linux)
- **Python Version**: 3.10+
- **Browser**: Any modern browser (Chrome, Firefox, Edge, etc)

### 🛠️ Additional Software Requirements
- [Git](https://git-scm.com/) for version control
- [GitHub Pages](https://pages.github.com/) for deployment
- Optional: [virtualenv](https://docs.python.org/3/library/venv.html) for environment isolation

---

We selected this stack to keep our implementation lightweight, portable, and easy to maintain. It supports rapid prototyping and aligns with our team’s strengths in Python and web development.
