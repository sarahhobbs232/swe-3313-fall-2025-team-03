# Implementation

This document provides all instructions required to configure, install, and run the Eternal Elixirs web application on **any machine** (Windows, macOS, or Linux).  
All dependencies are installed automatically through `requirements.txt`. No IDE (PyCharm, IntelliJ, Rider, VS Code, etc.) is required — the application runs entirely from the terminal.

---
